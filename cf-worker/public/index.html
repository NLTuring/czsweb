// 关于我们

协会简介

“创智算”数字科技协会聚焦竞赛培育、升学规划与前沿技术探索，致力于成为校内技术成长的第一站。协会以“技术 + 升学”为主线，为成员提供从入门到获奖的全链路支持。

孙国豪社长

协会持续吸收有热情、有特长的同学加入核心团队，一同把协会做大。
